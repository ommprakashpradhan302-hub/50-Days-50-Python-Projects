# 📄 Day 23 - Text File Reader

A Python program that reads the content of a text file and displays it on the screen with proper error handling.

## 🎯 Objective

To create a Text File Reader that allows users to open and view the contents of `.txt` files safely and efficiently.

## 🛠️ Concepts Used

- File Handling
- Exception Handling
- Functions
- User Input
- Output Formatting

## 📚 Required Libraries

This project uses Python’s built‑in features.  
No external libraries are required.

## ⚙️ How It Works

1. The user enters the filename of a text file.
2. The program attempts to open and read the file.
3. If the file exists, its content is displayed.
4. If the file does not exist or another error occurs, an error message is shown.
5. The program uses exception handling to manage errors gracefully.

## 💻 Example Output

```text
📄 TEXT FILE READER 📄
==============================

Enter the text file name (with .txt): sample.txt

==============================
File Content:

Hello, this is a sample text file.
It contains multiple lines of text.

==============================
```

*If the file is not found, the program displays: ❌ Error: File not found!*

## 🧠 What I Learned

- Opening and reading files in Python
- Handling exceptions with `try-except`
- Using functions for modular code
- Formatting output for clarity
- Building a practical utility for file management

## ▶️ How to Run

```bash
python main.py
```

Make sure the text file you want to read is in the same directory as the program, or provide the correct path.

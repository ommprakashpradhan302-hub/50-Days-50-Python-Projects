# ✅ To-Do List

A simple Python To-Do List application that allows users to add tasks, view all tasks, and delete tasks through a menu-driven interface.

This project is **Day 10** of my **50 Days 50 Python Mini Projects** challenge.

## 🚀 Features

- ➕ Add new tasks
- 👀 View all saved tasks
- 🗑️ Delete tasks by task number
- 📋 Menu-driven interface
- 🔄 Runs continuously until the user chooses to exit
- ⚠️ Handles invalid task numbers and invalid input

## 🛠️ Technologies Used

- **Python 3**
- No external libraries required

## 📚 Concepts Learned

- Creating and using lists
- Defining and calling functions
- Taking user input
- Using `while` loops
- Using conditional statements
- Using `enumerate()` to display numbered tasks
- Adding and removing list items
- Basic CRUD operations
- Exception handling with `try-except`

## ▶️ How to Run

Make sure Python 3 is installed on your computer.

Open the terminal inside the project folder and run:

```bash
python main.py
```

Follow the menu options displayed by the program.

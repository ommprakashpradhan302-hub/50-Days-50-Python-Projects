# 📝 Day 21 - Quiz Game

A Python program that runs a multiple-choice quiz, checks answers, and displays the final score with feedback.

## 🎯 Objective

To create a Quiz Game that tests knowledge interactively and provides instant feedback with a final score.

## 🛠️ Concepts Used

- Lists
- Dictionaries
- Loops
- Conditional Statements
- User Input
- Functions
- Output Formatting

## 📚 Required Libraries

This project uses only Python’s built-in features.  
No external libraries are required.

## ⚙️ How It Works

1. A list of questions is stored as dictionaries with options and correct answers.
2. The program displays each question with multiple-choice options.
3. The user enters their answer (A/B/C/D).
4. The program checks the answer and provides feedback.
5. The score is calculated and displayed at the end.
6. A percentage is shown along with motivational feedback.

## 💻 Example Output

```text
===== WELCOME TO THE QUIZ GAME! =====

Q1. What is the capital of India?
A. Delhi
B. Mumbai
C. Kolkata
D. Chennai
Your answer (A/B/C/D): A
✔ Correct!

Q2. Which programming language is this project based on?
A. Java
B. Python
C. C++
D. JavaScript
Your answer (A/B/C/D): B
✔ Correct!

===== QUIZ COMPLETED! =====
Your Score: 2 out of 2
Percentage: 100.00%
🎉 Excellent! Perfect Score! 🎉
```

*Questions and answers can be customized easily by editing the list.*

## 🧠 What I Learned

- Storing structured data using dictionaries
- Iterating through lists with loops
- Handling user input and validation
- Applying conditional logic for scoring
- Formatting output for clarity
- Building an interactive learning tool

## ▶️ How to Run

```bash
python main.py
```

No internet connection is required since questions are stored locally.

# 😄 Day 18 - Random Joke Generator

A Python program that displays a random joke each time the user runs the program, keeping things light and fun.

## 🎯 Objective

To create a Random Joke Generator that entertains users by showing a new joke on each run.

## 🛠️ Concepts Used

- Lists
- Random Module
- Functions
- User Input
- Conditional Statements
- Output Formatting

## 📚 Required Libraries

This project uses Python’s built-in `random` module.  
No external libraries are required.

## ⚙️ How It Works

1. A list of jokes is defined in the program.
2. The `random.choice()` function selects one joke at random.
3. The joke is displayed with formatting.
4. The user is asked if they want another joke.
5. If yes, the program runs again; if no, it exits with a friendly message.

## 💻 Example Output

```text
😄 RANDOM JOKE GENERATOR 🤭
------------------------------
Why don't scientists trust atoms? Because they make up everything!
------------------------------

Want another joke? (y/n): y
```

*Jokes are randomly selected, so output will differ each time.*

## 🧠 What I Learned

- Using Python’s `random` module
- Creating and accessing lists
- Writing reusable functions
- Handling user input
- Using conditional logic for program flow
- Building a fun interactive utility

## ▶️ How to Run

```bash
python main.py
```

No internet connection is required since jokes are stored locally.

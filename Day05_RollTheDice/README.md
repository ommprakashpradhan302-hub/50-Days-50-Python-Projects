# 🎲 Dice Roller

A simple Python dice roller that simulates rolling a six-sided die and displays a random number between 1 and 6.

This project is **Day 5** of my **50 Days 50 Python Mini Projects** challenge.

## 🚀 Features

- 🎲 Simulates a six-sided dice roll
- 🔢 Generates a random number between 1 and 6
- ⌨️ Allows the user to roll repeatedly
- 🔁 Uses a loop for repeated actions
- 🚪 Allows the user to quit by entering `q`

## 🛠️ Technologies Used

- **Python 3**
- `random` module

The `random` module is built into Python, so no external installation is required.

## 📚 Concepts Learned

- Importing and using the `random` module
- Creating functions
- Using `random.randint()`
- Taking user input
- Using `while` loops
- Using conditional statements
- Repeating actions based on user input
- Displaying results

## ▶️ How to Run

Make sure Python 3 is installed on your computer.

Open the terminal inside the project folder and run:

```bash
python main.py
```

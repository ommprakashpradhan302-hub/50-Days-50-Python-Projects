# 🔐 Password Generator

A simple Python password generator that creates random passwords using letters, numbers, and special characters.

This project is **Day 3** of my **50 Days 50 Python Mini Projects** challenge.

## 🚀 Features

- 🔤 Uses uppercase and lowercase letters
- 🔢 Includes numbers
- 🔣 Includes special characters
- 📏 Lets the user choose the password length
- 🎲 Generates random characters
- 🔀 Shuffles the generated characters

## 🛠️ Technologies Used

- **Python 3**
- `random` module
- `string` module

Both modules are built into Python, so no external installation is required.

## 📚 Concepts Learned

- Importing and using Python modules
- Working with strings
- Creating functions
- Using lists
- Using `for` loops
- Using `random.choice()`
- Using `random.shuffle()`
- Joining list elements into a string
- Taking user input

## ▶️ How to Run

Make sure Python 3 is installed on your computer.

Open the terminal inside the project folder and run:

```bash
python main.py
```

## 🖥️ Example Output

```text
Enter password length: 12

Generated Password: a@9Kz!pL2#xQ7
Password generated successfully! 🔐
```

> **Note:** The generated password will be different each time because the characters are selected randomly.

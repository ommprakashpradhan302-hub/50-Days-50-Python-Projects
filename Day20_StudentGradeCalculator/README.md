# 📊 Day 20 - Student Grade Calculator

A Python program that calculates total marks, percentage, and assigns a grade based on the student’s performance.

## 🎯 Objective

To create a Student Grade Calculator that helps evaluate academic performance by computing total marks, percentage, and grade.

## 🛠️ Concepts Used

- Lists
- Loops
- Functions
- Conditional Statements
- User Input
- Calculations
- Output Formatting

## 📚 Required Libraries

This project uses only Python’s built-in features.  
No external libraries are required.

## ⚙️ How It Works

1. The user enters the number of subjects.
2. The program collects subject names and marks.
3. The `calculate_grade()` function computes:
   - Total marks
   - Percentage
   - Grade based on percentage
4. Results are displayed with proper formatting.

## 💻 Example Output

```text
=== STUDENT GRADE CALCULATOR ===
Enter number of subjects: 5
Enter subject 1 name: Math
Enter marks for Math (out of 100): 88
Enter subject 2 name: Physics
Enter marks for Physics (out of 100): 76
Enter subject 3 name: Chemistry
Enter marks for Chemistry (out of 100): 82
Enter subject 4 name: English
Enter marks for English (out of 100): 65
Enter subject 5 name: Computer Science
Enter marks for Computer Science (out of 100): 91

===== RESULT =====
Total Marks: 402 out of 500
Percentage: 80.40%
Grade: A
```

*Grades are assigned based on percentage ranges (A+, A, B, C, D, F).*

- Performing percentage calculations

```bash
python main.py
```

# 🌡️ Day 13 - Temperature Converter

A simple Python Temperature Converter that allows the user to convert temperatures between Celsius, Fahrenheit, and Kelvin.

## 🎯 Objective

To create a Temperature Converter that allows users to convert temperatures between:
- Celsius
- Fahrenheit
- Kelvin

## 🛠️ Concepts Used

- User Input
- Conditional Statements
- Conversion Formulas
- Functions
- Output Formatting

## 📚 Required Libraries

No external libraries are required. The project uses only built-in Python features.

## ⚙️ How It Works

1. The program displays a menu with different temperature conversion options.
2. The user selects a conversion option.
3. The user enters the temperature value.
4. The corresponding conversion function is called.
5. The converted temperature is displayed with the correct unit.
6. Invalid options are handled with an error message.

## 🔄 Available Conversions

- Celsius → Fahrenheit
- Celsius → Kelvin
- Fahrenheit → Celsius
- Fahrenheit → Kelvin
- Kelvin → Celsius
- Kelvin → Fahrenheit

## 🧮 Conversion Formulas

- °F = (°C × 9/5) + 32
- K = °C + 273.15
- °C = (°F − 32) × 5/9
- K = (°F − 32) × 5/9 + 273.15
- °C = K − 273.15
- °F = (K − 273.15) × 9/5 + 32

## ▶️ How to Run

```bash
python main.py
```

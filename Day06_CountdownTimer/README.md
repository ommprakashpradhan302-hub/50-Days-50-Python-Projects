# ⏳ Countdown Timer

A simple Python countdown timer that takes a time value in seconds from the user and counts down to zero.

This project is **Day 6** of my **50 Days 50 Python Mini Projects** challenge.

## 🚀 Features

- ⏱️ Takes time in seconds from the user
- 🔢 Displays the countdown in `MM:SS` format
- 🔄 Counts down one second at a time
- ⚠️ Handles invalid input
- 🚫 Rejects negative numbers
- 🎉 Displays a message when the countdown reaches zero

## 🛠️ Technologies Used

- **Python 3**
- `time` module

The `time` module is built into Python, so no external installation is required.

## 📚 Concepts Learned

- Importing and using the `time` module
- Taking user input
- Using `while` loops
- Using conditional statements
- Using `time.sleep()`
- Converting seconds into minutes and seconds
- Formatting output
- Handling `ValueError`

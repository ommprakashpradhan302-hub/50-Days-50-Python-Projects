🧮 Simple Calculator

A beginner-friendly Python calculator that performs basic arithmetic operations using user input.

This project is Day 1 of my 50 Days 50 Python Mini Projects challenge.

🚀 Features

The calculator can perform:

- ➕ Addition
- ➖ Subtraction
- ✖️ Multiplication
- ➗ Division
- ⚠️ Division-by-zero handling
- ❌ Invalid-choice handling

🛠️ Technologies Used

- Python 3
- "input()"
- "float()"
- "if / elif / else"
- Basic arithmetic operators

📂 Project Structure
```
Day-01-Simple-Calculator/
│
├── calculator.py
└── README.md
```
▶️ How to Run

Make sure Python 3 is installed on your computer.

Open the terminal inside this project folder and run:
```
python calculator.py
```
Then enter the two numbers and choose an operation.

💻 Example
```python
====== SIMPLE CALCULATOR ======
Enter first number: 10
Enter second number: 5

Select operation:
1. Addition (+)
2. Subtraction (-)
3. Multiplication (*)
4. Division (/)

Enter your choice (1/2/3/4): 1
```
```
Result: 15.0
```

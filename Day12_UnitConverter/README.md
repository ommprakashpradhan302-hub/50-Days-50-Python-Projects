# 🔄 Day 12 - Unit Converter

A simple Python Unit Converter that allows the user to convert between different units of length, weight, and temperature.

## 🎯 Objective

To create a Unit Converter that allows users to convert different units of:
- Length
- Weight
- Temperature

## 🛠️ Concepts Used

- User input
- Conditional statements
- Conversion formulas
- Functions
- Output formatting
- While loop
- Menu-driven program

## 📚 Required Libraries

No external libraries are required.

## ⚙️ How It Works

1. The program displays a main menu.
2. The user selects a conversion category.
3. The user enters a value to convert.
4. The appropriate conversion formula is applied.
5. The converted value is displayed.
6. The menu continues until the user chooses to exit.
7. Invalid options are handled with an error message.

## 📏 Available Conversions

### Length
- Kilometers → Meters
- Meters → Kilometers

### Weight
- Kilograms → Grams
- Grams → Kilograms

### Temperature
- Celsius → Fahrenheit
- Fahrenheit → Celsius

## ▶️ How to Run

```bash
python main.py
```


# ✨ Day 16 - Random Quote Generator

A Python program that displays a random inspirational quote each time the user runs the program.

## 🎯 Objective

To create a Random Quote Generator that motivates users by showing a new inspirational quote on each run.

## 🛠️ Concepts Used

- Lists
- Random Module
- Functions
- Output Formatting
- String Manipulation

## 📚 Required Libraries

This project uses Python’s built-in `random` module.  
No external libraries are required.

## ⚙️ How It Works

1. A list of inspirational quotes is defined in the program.
2. The `random.choice()` function selects one quote at random.
3. The selected quote is displayed with formatting.
4. A motivational message is shown after the quote.

## 💻 Example Output

```text
========================================
 RANDOM QUOTE GENERATOR 
========================================

'Believe you can and you're halfway there.'

Keep going and never give up! 💪
```

*Quotes are randomly selected, so output will differ each time.*

## 🧠 What I Learned

- Using Python’s `random` module
- Creating and accessing lists
- Writing reusable functions
- Formatting console output
- Building a simple motivational utility

## ▶️ How to Run

```bash
python main.py
```

No internet connection is required since quotes are stored locally.

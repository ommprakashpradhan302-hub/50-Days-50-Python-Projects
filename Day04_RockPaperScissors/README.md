# ✊📄✂️ Rock Paper Scissors

A simple Python game where the user plays **Rock, Paper, Scissors** against the computer.

This project is **Day 4** of my **50 Days 50 Python Mini Projects** challenge.

## 🚀 Features

- ✊ Rock
- 📄 Paper
- ✂️ Scissors
- 🎲 Computer randomly selects a choice
- ⌨️ Takes the user's choice as input
- 🏆 Determines the winner using game rules
- ❌ Handles invalid choices

## 🛠️ Technologies Used

- **Python 3**
- `random` module

The `random` module is built into Python, so no external installation is required.

## 📚 Concepts Learned

- Importing the `random` module
- Creating and working with lists
- Taking user input
- Using `.lower()`
- Using `random.choice()`
- Conditional statements
- Building game logic
- Comparing values
- Displaying results

## ▶️ How to Run

Make sure Python 3 is installed on your computer.

Open the terminal inside the project folder and run:

```bash
python main.py
```


## 🖥️ Example Output

```text
Enter your choice (rock 🪨 / paper 📄 / scissors ✂️):   rock
You chose: rock
Computer chose: paper
😢 You Lose!
```

> **Note:** The computer's choice is random, so the result can be different each time you play.

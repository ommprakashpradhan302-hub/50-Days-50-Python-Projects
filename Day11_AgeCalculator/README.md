# 📅 Day 11 - Age Calculator

A simple Python Age Calculator that takes the user's birth date and calculates their current age in years, months, and days.

## 🎯 Objective

To create an Age Calculator that takes the user's date of birth and calculates their current age.

## 🛠️ Concepts Used

- Date handling
- `datetime` module
- User input
- Calculations
- Output formatting
- Conditional statements

## 📚 Required Libraries

- `datetime` (built-in)

No external libraries are required.

## ⚙️ How It Works

1. The program takes the user's birth day, month, and year.
2. It gets the current date using `date.today()`.
3. A date object is created for the user's birth date.
4. The difference between the current date and birth date is calculated.
5. The program adjusts the months and days when necessary.
6. The final age is displayed in years, months, and days.

## ▶️ How to Run

Make sure Python is installed on your computer.

```bash
python main.py
```

## 💻 Example Output

```text
📅 Welcome to Age Calculator 📅

Enter your birth day (DD): 15
Enter your birth month (MM): 08
Enter your birth year (YYYY): 2000

🎉 Your Age is: 25 years, 0 months, 4 days.
```

*The exact age will change depending on the current date and the date entered.*
